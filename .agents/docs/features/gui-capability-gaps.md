# Close remaining GUI capability gaps

## Goal

Complete high-value desktop/mobile capabilities not covered by task search or basic mobile support.

## Candidate scope

- Rich Markdown notes editing
- Workspace storage-folder relocation
- Verified macOS packaging
- Measured startup performance and optimization if needed
- Multiple windows only if a concrete workflow requires them

Prioritize each item before implementation; this record is not a commitment to ship all candidates together.
