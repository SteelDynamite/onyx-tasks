# Task search and filtering

## Goal

Let users quickly find tasks across lists and workspaces, then narrow results by useful task attributes.

## Scope

Start with title and description search. Define cross-workspace behavior, date/status filters, ranking, and indexing only when implementation begins; do not add an index before scale requires it.

## Done when

Desktop and mobile users can search without disrupting list ordering, grouping, or task navigation.
